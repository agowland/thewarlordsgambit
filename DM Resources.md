### Tools
- [Great for creating random geography, but there are other tools on the donjon site too](https://donjon.bin.sh/fantasy/maps/)
- [Lore Frog digital lore repository](https://lorefrog.com/) 
- [Chronica is a campaign management tool; free version seems very meh but functionality in the paid tiers include things like campaign shops, places, encounters and a file hub](https://chronica.ventures/)
- [Daggerheart Brews is a custom card creator that will do Ancestries, Communities, Transformations, Equipment, Domain, Classes and Subclasses; there's also a tool to create adversaries](https://www.daggerheartbrews.com/)
- [Freshcutgrass.app is a fantastic encounter builder that also supports publicly posted adversaries, locations, etc](https://freshcutgrass.app/)
- [Daggerdice looks like an **incredibly important** tool for building appropriately scaled encounters](https://daggerdice.com/)
- [Campaign Logger is a freemium tool for logging sessions using a tagging system that cross-references locations, NPCs, items, etc. There are no examples to see what it actually looks like..](https://www.campaign-logger.com/)
- [Eldritch Foundry is a mini-builder alternative to Hero Forge; different species and options than Hero Forge, but quality looks similar or the same](https://creator.eldritch-foundry.com/)
- [Daggerstack digital character sheets -- looks awesome](https://daggerstack.com/)
